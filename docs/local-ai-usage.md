# 本地文字 AI 使用说明

本版本增加 Qwen3.5-0.8B Q8 和 LFM2.5-1.2B-Instruct Q8。它们处理语音识别后的文字，语音识别引擎仍独立设置。安装后保留原提供商，不自动下载模型。

1. 在设置 → AI 设置 → 本地模型中下载模型。Qwen 文件约 812 MB，LFM 约 1.25 GB；下载可取消、续传，完整校验后才能启用。
2. 选择“自动选择设备”或“仅 CPU”，点击启用。自动模式优先 NVIDIA CUDA，失败回退 CPU；状态显示实际设备。两个模型可同时保存在磁盘，只加载一个。
3. 为需要的文字功能选择“本地模型”，或点击一键全部切换。整体切换会保存原云端配置，可恢复。各功能原来的开关继续有效。
4. 模型切换等待当前生成结束。可以取消任务、释放内存、重新加载；释放后下一次使用会重新加载。删除模型必须确认。

本地文字处理不调用云端视觉、搜索或云端文字模型回退。设置同时显示当前语音识别是否在线；只有识别和文字处理都采用本地方式，才是完整离线处理。下载模型仍需要网络。

输入长度有限制，超长请求、截断、空输出、结构错误会报错。普通听写润色失败保留识别原文；翻译、编辑、助手和审核失败不会伪装成功。小模型仍可能在结构正确时误改内容，请核对数字、否定、专有名词和任务约束。

Qwen 使用 Apache-2.0；LFM 使用独立的 LFM Open License，涉及企业商用条件，下载前可在模型卡片查看完整许可。安装包携带推理运行时及第三方声明，不包含两款模型权重，无需另装 Ollama 或 Python。安装包包含 CPU、CUDA 和原语音引擎组件，体积较大。

当前开发机测试更支持优先试用 Qwen。此结论仅来自固定样例，不能代替个人语料验收，也不意味着达到云端模型质量。详见 [样例对比](local-ai-evaluation.html) 和 [验证记录](local-ai-validation.md)。

开发构建：`python scripts/prepare_local_llm.py` 准备锁定资源；`pnpm tauri build --config src-tauri/tauri.local-ai.conf.json` 构建并检查前端体积。本机若在程序编译成功后出现 NSIS 文件读取失败，执行 `python scripts/package_local_llm_windows.py`，使用 Tauri 已生成的安装脚本在非同步目录打包。CPU/CUDA 运行时锁定 b11118，资源清单包含 SHA-256；不得直接替换为最新版。
